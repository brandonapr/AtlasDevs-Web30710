# Checklist de evidencias finales

Lista de apoyo para preparar la sustentacion y comprobar que el proyecto cuenta con evidencias suficientes.

## Gestion y seguimiento

- [ ] Captura del tablero Jira.
- [ ] Captura del Timeline o cronograma.
- [ ] Backlog actualizado.
- [ ] Commits recientes visibles en GitHub.
- [ ] Ramas y merges principales identificados.

## Producto funcional

- [ ] Menu publico funcionando.
- [ ] Registro de pedido con carrito.
- [ ] Login con usuarios de prueba.
- [ ] Vista de caja.
- [ ] Vista de cocina.
- [ ] Vista de mesera.
- [ ] Vista de administracion.

## Backend y datos

- [ ] Supabase con productos cargados.
- [ ] Perfiles vinculados a usuarios Auth.
- [ ] Pedidos registrados en tablas.
- [ ] Estados del pedido verificados.
- [ ] Pago y cierre de ticket revisados.

## Pruebas

- [ ] `npm.cmd run build:static`.
- [ ] `npm.cmd run build:web --if-present`.
- [ ] `npm.cmd run test:roles`.
- [ ] `npm.cmd run check:supabase`.
- [ ] `npm.cmd run check:supabase -- --auth`.
- [ ] `npm.cmd run test:mvp` si existe `.env` local con secret key.

## Despliegue

- [ ] Render en estado Deployed.
- [ ] Commit desplegado identificado.
- [ ] Rutas `/menu`, `/login`, `/caja`, `/cocina`, `/mesera` revisadas.

## Documentacion

- [ ] README principal revisado.
- [ ] Documentacion de planificacion revisada.
- [ ] Guia de Supabase revisada.
- [ ] Guia de pruebas revisada.
- [ ] Evidencias de participacion por integrante preparadas.
