# Planificacion

Esta carpeta documenta la gestion del proyecto EDValleDigital: acuerdos, backlog, sprints, estructura, responsables y automatizacion del trabajo.

## Archivos

| Archivo | Contenido |
| --- | --- |
| `automatizacion-proyecto.md` | Reglas para issues, ramas, pull requests y trazabilidad. |
| `backlog.md` | Backlog ejecutado y pendientes priorizados. |
| `colaboradores-y-asignaciones.md` | Roles del equipo y asignaciones recomendadas. |
| `distribucion-y-ejecucion.md` | Flujo de trabajo, ramas, RACI y Definition of Done. |
| `estructura-proyecto.md` | Organizacion tecnica y alcance actual. |
| `plan-scrum-retrospectivo-rf01-rf02.md` | Plan Scrum por sprints para RF01 y RF02. |
| `requests-y-backlog-inicial.md` | Requests iniciales, epicas e historias base. |
| `sprint-01.md` | Sprint de menu digital y registro de pedidos. |

## Uso en sustentacion

- Mostrar `backlog.md` para evidenciar avance progresivo.
- Mostrar `distribucion-y-ejecucion.md` para explicar roles y flujo de ramas.
- Mostrar `plan-scrum-retrospectivo-rf01-rf02.md` para relacionar requisitos, sprints y entregables.

## Regla de actualizacion

Cada cambio funcional relevante debe quedar reflejado en backlog, sprint o informe de estado para sostener la trazabilidad del proyecto.
