# Jira

Archivos de apoyo para registrar backlog, sprints y sesiones en Jira.

## Archivos disponibles

| Archivo | Proposito |
| --- | --- |
| `jira-import-calendario.csv` | Backlog base y calendario general del proyecto. |
| `jira-backlog-rf01-rf02-retrospectivo.csv` | Actividades retrospectivas para RF01 y RF02. |
| `jira-backlog-sesion-2026-06-17.csv` | Tareas de la sesion de verificacion de Render, commit y evidencias. |

## Uso recomendado

1. Revisar el CSV antes de importarlo.
2. Crear primero epicas o sprint si Jira lo requiere.
3. Asignar fechas para que las tareas aparezcan en Timeline.
4. Adjuntar capturas de Jira, Render, GitHub y Supabase como evidencia.
