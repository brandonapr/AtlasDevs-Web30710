# Documentacion del proyecto

Esta carpeta concentra las evidencias de planificacion, diseno, seguimiento y control del proyecto EDValleDigital.

## Mapa de carpetas

| Carpeta | Contenido | Uso recomendado |
| --- | --- | --- |
| `actas/` | Actas formales en PDF/DOCX | Evidencia de reuniones y acuerdos. |
| `diseno/` | Actividades y material de diseno | Sustentar analisis, interfaz y decisiones visuales. |
| `estado/` | Informes de estado tecnico y funcional | Mostrar cortes de avance y pendientes. |
| `jira/` | CSV para backlog, sprint y sesiones | Importar o copiar tareas a Jira. |
| `planificacion/` | Backlog, sprints, estructura y distribucion | Evidenciar gestion Scrum y seguimiento. |

## Evidencias principales para sustentacion

- Planificacion inicial: `planificacion/distribucion-y-ejecucion.md`.
- Backlog del proyecto: `planificacion/backlog.md`.
- Sprint de menu y pedidos: `planificacion/sprint-01.md`.
- Plan Scrum retrospectivo: `planificacion/plan-scrum-retrospectivo-rf01-rf02.md`.
- Estado de login y requisitos: `estado/INFORME_ESTADO_LOGIN_REQUISITOS_2026-06-17.md`.
- Insumos de Jira: `jira/`.

## Regla de organizacion

Los documentos que sean solo de revision personal o borradores temporales no deben versionarse. Para esos casos usar una carpeta local fuera del repositorio, por ejemplo `C:\tmp`.
